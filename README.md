# Academia_Unity 🎮

Welcome to Academia_Unity! This is a learning repository for beginners who want to learn C# programming with Unity.

## 📚 What is this?

This repository contains simple, easy-to-understand C# examples for Unity. Every piece of code is explained like you're learning programming for the first time. No complicated words, just simple explanations!

## 🎯 Learning Goals

- Understand basic C# programming concepts
- Learn how to write simple Unity scripts
- See examples with clear, beginner-friendly comments
- Practice coding in the simplest way possible

## 📖 How to Use This Repository

1. Start with the scripts in the `Assets/Scripts/Basics/` folder
2. Read the comments in each file - they explain everything step by step
3. Try changing the code and see what happens
4. Have fun learning!

## 🌟 What You'll Learn

- **HelloWorld.cs** - Your first Unity script and how to print messages
- **Variables.cs** - What are variables and how to use them
- **Conditionals.cs** - Making decisions in code (if/else)
- **Loops.cs** - Repeating actions in code
- **Functions.cs** - Creating reusable pieces of code

## 💡 Remember

- There are no stupid questions in programming
- Making mistakes is how we learn
- Every expert was once a beginner
- Take your time and practice!
