# 🚀 Quick Start Guide

## How to Use These Scripts in Unity

### Step 1: Open Unity
1. Open Unity Hub
2. Create a new 3D or 2D project
3. Name it something like "LearningCSharp"

### Step 2: Add the Scripts
1. In Unity, look for the "Project" window (usually at the bottom)
2. Find the "Assets" folder
3. Copy the scripts from this repository into your Unity project's Assets folder

### Step 3: Attach a Script to a GameObject
1. In Unity, right-click in the "Hierarchy" window
2. Select "Create Empty" to make a new GameObject
3. Rename it to something like "LearningObject"
4. In the "Inspector" window (usually on the right), click "Add Component"
5. Type the name of the script you want to try (like "HelloWorld")
6. Select the script to attach it

### Step 4: Run and See the Output
1. Click the "Play" button at the top of Unity (the triangle ▶️)
2. Look at the "Console" window (usually at the bottom)
3. You should see the messages from your script!

### Tip: View the Console
- If you don't see the Console window, go to: Window → General → Console
- The Console shows all Debug.Log messages

## 📋 Order to Try the Scripts

Try them in this order:
1. **HelloWorld.cs** - Start here!
2. **Variables.cs** - Learn about storing information
3. **Conditionals.cs** - Learn about making decisions
4. **Loops.cs** - Learn about repeating actions
5. **Functions.cs** - Learn about organizing code

## 🎮 What You'll See

When you run each script, you'll see messages in the Console window. These messages explain what the code is doing and help you understand how it works.

## 💡 Experimenting

- Try changing the numbers in the code
- Try changing the text in Debug.Log()
- Try adding your own Debug.Log() messages
- Don't worry about breaking things - you can always reset!

## ❓ Having Trouble?

- Make sure the script is attached to a GameObject
- Make sure you pressed the Play button
- Check the Console window for any error messages
- Read the comments in the code files - they explain everything!

## 🎉 You're Ready!

You now know how to:
- Create a Unity project
- Add C# scripts
- Attach scripts to GameObjects
- Run your code and see the results

Now go explore the scripts and have fun learning! 🚀
